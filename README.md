# 读书阅读器 du-shu-reader

> 一款本地优先的桌面电子书阅读器：TXT / EPUB / PDF，完全离线，数据属于你。

没有账号、没有书城、不做推荐——打开就能安静地读书。所有书籍、进度、划线与笔记都保存在你自己的电脑上，并且随时可以导出带走。

## 功能特性

- **三种格式**：TXT（自动识别 UTF-8/GBK 编码，网文友好）、EPUB（章节 / 目录 / 图片）、PDF（内置文字层，正文可选中复制）
- **顺手翻页**：左右点击翻页区 + 悬浮翻页按钮 + 键盘方向键 / 空格，页码实时显示
- **划线与笔记**：选中正文即可划线、写笔记、加书签；标注抽屉统一管理、一键跳转原文
- **三种主题**：纸张 / 护眼绿 / 深色，一键切换；深色模式下 PDF 页面自动反相
- **章节目录**：TXT 自动识别"第X章"式章节，EPUB 使用书源自带目录，抽屉内点击跳转
- **阅读统计**：按书累计、按日累计阅读时长，书架一目了然
- **数据可携**：一键备份 / 恢复（JSON，含书籍与标注），划线笔记可导出 Markdown

## 快速开始

环境要求：Node.js ≥ 22（建议 LTS），npm 10+。

```bash
# 国内网络建议先配置 Electron 镜像，否则二进制下载可能超时
# export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/

npm install
npm start          # 开发模式启动（热更新）
```

## 构建与测试

```bash
npm run package    # 产出免安装应用（out/ 目录）
npm run make       # 产出 Windows 安装包（Squirrel）
npm test           # 单元测试（核心逻辑 49 项）
npm run typecheck  # TypeScript 类型检查
```

## 技术栈

| 层 | 选型 |
|---|---|
| 应用外壳 | Electron（单实例锁、沙箱 + 上下文隔离） |
| UI | React 19 + TypeScript（strict） |
| 构建 | Vite 8 + Electron Forge（官方 Vite 模板） |
| 数据 | IndexedDB（书籍 / 进度 / 标注 / 时长）+ localStorage（设置） |
| 渲染 | pdfjs-dist（PDF）；自研零依赖 ZIP / EPUB 解析器 |

核心逻辑（编码识别、分页、书库、备份、EPUB 解析）是与 DOM / Electron 无关的纯模块，Node 环境直接单测。

## 数据与隐私

应用不会联网上传任何数据。更换电脑或重装系统前，请在书架点击「**备份**」导出 JSON 文件；划线与笔记可通过「**笔记**」导出为 Markdown 长期保存。恢复按书去重，重复导入不会产生副本。

## 已知限制

- EPUB 目前整本渲染，数百章的超大书籍首屏偏慢（懒渲染在计划中）
- 暂无自动更新；UI 层自动化测试尚未覆盖（核心逻辑已有 49 项单测）
- 同一时间只允许运行一个应用实例（双开会自动聚焦已有窗口）
